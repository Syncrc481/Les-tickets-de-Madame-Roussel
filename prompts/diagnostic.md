pus# Modèle de prompt de diagnostic

Tu m’aides à trouver la cause d’un bug sur la page de Madame Roussel.

1. Propose trois hypothèses au plus, classées par probabilité.
2. Pour chacune, indique comment la vérifier dans le navigateur.
3. Ne propose aucun correctif à ce stade.

<symptome>[Décrire ce qui se passe et, si possible, le message affiché.]</symptome>
<etapes>[Indiquer les actions et les données nécessaires pour reproduire le problème.]</etapes>
<attendu>[Décrire le comportement attendu.]</attendu>
